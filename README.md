# 📈 Price Elasticity & Profitability Simulator

An interactive, real-time analytics dashboard built with React, Recharts, and Tailwind CSS. This tool helps businesses analyze price elasticity, simulate demand curves, optimize pricing strategy, and calculate profit margins dynamically.

---

## ✨ Features

- **Dynamic Parameter Control:** Adjust Base Price, Unit Cost, Competitor Pricing, Marketing Budget, and Day Types in real time.
- **Real-Time Financial Analytics:** Calculates Optimal Price, Max Revenue, Net Profit, and Profit Margin percentage.
- **Interactive Visualization:** Plotted Demand, Revenue, and Profit curves using `Recharts` with custom tooltips and optimal price reference lines.
- **Scenario Breakdown Table:** Detailed financial comparison across multiple price points with baseline and optimal scenario highlights.
- **CSV Data Export:** Export simulated pricing and profitability metrics for offline analysis.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Lucide React (Icons)
- **Data Visualization:** Recharts
- **API Client:** Axios
- **Deployment:** Vercel
